# TNBA Omaha Senate Tournament

Public preview website for the 39th Annual TNBA Cornhusker Classic in Omaha, Nebraska.

The site includes:

- Searchable individual bowlers
- Singles, doubles, mixed doubles, teams, All Events, and Senior standings
- Bowler and entry detail panels
- Division high games and series
- Official tournament dates, squad times, rules, and contact information

The current data contains the official first-week results published July 19, 2026.

## Running locally

Open `index.html` directly or serve this folder from any static web server.

```powershell
python -m http.server 8080
```

Then visit `http://localhost:8080`.
